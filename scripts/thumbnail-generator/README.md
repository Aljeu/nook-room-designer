# Prepared catalogue previews

Run `npm run thumbnails:prepare` from the project root, open the printed local URL in a WebGL-capable browser, and choose **Generate previews**. The process renders the current available furniture, wall objects, window styles and doors using their default models, finishes, cameras and lighting. It writes PNGs to `public/thumbnails/` and a lookup manifest to `src/ui/prepared-thumbnails.json` only after the whole set succeeds. If source files change while generating, the run is rejected and the previous previews remain. Stop the preparation server with Ctrl-C when finished. It uses port 5188 and does not touch room saves or the editor's server.

Run `npm run thumbnails:check` after changes to models, materials, catalogue definitions or preview settings. It checks the source fingerprint, files and current catalogue coverage. Regenerate and commit both PNGs and manifest together when the check fails. Image rendering may vary slightly between graphics drivers; use the same browser/environment when comparing visual output. A missing, failed or stale preview displays the existing decorative fallback; normal catalogue browsing does not load a model family just to render a thumbnail.
